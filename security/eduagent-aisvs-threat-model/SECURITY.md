# Security and Responsible Use

This project is intended for defensive security review, architecture analysis, education, and authorized testing.

Do not use the lab scenarios, controls, or validation workflow against systems that you do not own, administer, or have written permission to test.

Use only synthetic data in exercises and demonstrations. Do not place student records, credentials, grades, institutional secrets, personal data, or production system details in this repository or in lab runs.

The lab material is designed for local or mocked environments. It should not be treated as permission to test a learning platform, school system, model provider, tool server, or identity provider.

If you find a security issue in a real system while using these materials, coordinate disclosure with the system owner through their published security reporting process.

This repository does not include operational exploit code. Contributions should stay focused on defensive analysis, evidence collection, risk modeling, and authorized validation.
